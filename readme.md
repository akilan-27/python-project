🤖 FunBot - Simple Offline CLI Chatbot



FunBot is a lightweight command-line chatbot built entirely in Python. It works offline without any APIs or external dependencies and provides fun interactive activities such as jokes, riddles, word games, fun facts, friendly roasts, and score tracking.



🚀 Features



😂 Random Jokes



Get a random joke each time you select the joke option.



📚 Fun Facts



Learn interesting and surprising facts from various topics.



🧩 Riddles



\* Solve interactive riddles.

\* Request hints when needed.

\* Skip questions and reveal answers.

\* Earn points for correct answers.



🎮 Word Guessing Game



\* Guess hidden words using clues.

\* Maximum of 6 attempts.

\* Score points based on performance.



😄 Friendly Roasts



Receive humorous and light-hearted roasts.



🏆 Score Tracking



Track:



\* Total points earned

\* Correct riddles solved

\* Total riddles attempted



⏰ Current Date and Time



Display the current system date and time.



💬 Interactive Conversation



FunBot can respond to:



\* Hello

\* Hi

\* Hey

\* Thanks

\* How are you?

📋 Available Commands



| Command | Description                |

| ------- | -------------------------- |

| joke    | Hear a random joke         |

| fact    | Get a fun fact             |

| riddle  | Solve a riddle             |

| game    | Play a word guessing game  |

| roast   | Get a friendly roast       |

| score   | View your score            |

| time    | Show current date and time |

| menu    | Display available options  |

| bye     | Exit FunBot                |
